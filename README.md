# italian-gaze-attention

# Italian Gaze–Attention Analysis

Code and results for the seminar project **“Do Italian Transformer Encoders Show the Same Gaze–Attention Patterns?”**

This project compares layer-wise associations between human eye-tracking measures and self-attention across three Italian transformer encoders: **GilBERTo, BERT XXL, and ELECTRA XXL**, using the Italian MECO eye-tracking data.

The repository contains the experiment notebook and generated results.

## Original Code

This project builds on the code and methodology of Dini et al. (2025):

[ORIGINAL REPOSITORY](https://github.com/Andrew-Wyn/augmenting_nlms_meco)

The notebook contains the setup, model extensions, and analyses performed for this seminar project.

## Data

Eye-tracking data are from the **Multilingual Eye-Movement Corpus (MECO)** (Siegelman et al., 2022).
